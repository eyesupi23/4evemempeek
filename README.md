# 絵当て (Eate) — เกมทายภาพ

เกมทายภาพสไตล์ 8-bit ญี่ปุ่น โทนสว่าง — React + TypeScript + Tailwind CSS v4 + Vite

## เริ่มใช้งาน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # build ไว้ที่ dist/
```

## กติกา

- ก่อนเริ่ม เลือก "推し" (สิ่งที่ชอบที่สุด) 1 จาก 7 อย่าง
- ทายภาพทั้งหมด 7 × 7 = 49 ข้อ (แต่ละอย่างมี 7 ภาพ สุ่มลำดับ)
- ภาพถูกปิดด้วยป้ายไม้ 9 แผ่น (grid 3×3) เริ่มเปิด 1 แผ่น
- เวลาลดลงเรื่อย ๆ และเปิดป้ายเพิ่มทุก 1/3 ของเวลา (สูงสุด 3 แผ่น)
- ทุกภาพใช้ตัวเลือกชุดเดียวกัน 7 ข้อ เรียงลำดับเดิมเสมอ
- ตอบถูกได้คะแนนตามจำนวนป้ายที่เปิด: เปิด 1 / 2 / 3 / 4 / 5 แผ่น = 5 / 4 / 3 / 2 / 1 คะแนน (ภาพโบนัส x5 = 25 / 20 / 15 / 10 / 5)
- เวลาหมดหรือตอบผิด = 0 คะแนน
- คีย์บอร์ด: `1-7` เพื่อตอบ, `Enter` ไปข้อต่อไป

## สรุปผล

ตอนจบเกมจะจัดอันดับทั้ง 7 อย่างตามคะแนนที่ได้จากภาพของแต่ละอัน แล้วเทียบกับอันที่เลือกไว้ (เมน)

- perfect — ได้คะแนนเต็มทุกคนครบทั้ง 7
- match — เมนที่เลือกได้คะแนนสูงสุด (เสมออันดับ 1 ก็นับ)
- other — คนอื่นได้คะแนนมากกว่าเมนที่เลือก
- none — ไม่ถูกเลยสักข้อ

ข้อความทั้งหมดแก้ได้ใน `VerdictCard` ที่ `src/components/ResultScreen.tsx` และเกณฑ์อยู่ใน `buildRanking` / `verdictFor` ที่ `src/game/logic.ts`

## เปลี่ยน 7 อย่างที่ชอบ

แก้ใน `src/data/choices.ts` — แต่ละอันมี `id` (ใช้อ้างอิงในคำถาม), `name` (ชื่อที่แสดง) และ `avatar` (รูปในหน้าเลือกและหน้าสรุป)

## ใส่รูปของคุณเอง

1. วางรูปไว้ใน `public/images/<id>/` เช่น `public/images/koi/` (รูปสี่เหลี่ยมจัตุรัสดีที่สุด)
2. แก้ `src/data/questions.ts` เปลี่ยน `sample("koi")` เป็น

```ts
...photosOf("koi", ["/images/koi/a.jpg", "/images/koi/b.jpg", /* … */]),
...photosOf("koi", [...], 20),   // ใส่เลขท้ายเพื่อกำหนดเวลา (วินาที) ให้ชุดนั้น
```

แต่ละอย่างควรมี 7 ภาพเท่ากัน (มากหรือน้อยกว่าก็ได้ หน้าสรุปจะแสดงเป็น ถูก/ทั้งหมด ของแต่ละอัน)

## ปรับแต่ง

- `src/game/config.ts` — เวลาเริ่มต้น, จำนวนป้ายสูงสุด, คะแนน, สุ่มลำดับข้อ
- `src/index.css` — สี (washi, sumi, shu, ai, matcha ฯลฯ) และฟอนต์ใน `@theme`
- `scripts/make-sprites.py` — สร้างภาพ pixel art ตัวอย่าง 49 ภาพ (7 แบบต่ออัน)

## โครงสร้าง

```
src/
  data/choices.ts       7 อย่างที่ชอบ (ใช้เป็นตัวเลือกทุกภาพ)
  data/questions.ts     รายการภาพ 49 ข้อ
  game/                 config, types, logic (สุ่ม/คิดคะแนน), sound (เสียง 8-bit)
  hooks/useGame.ts      state ของเกม + ตัวจับเวลา
  components/           TitleScreen, PickScreen, GameScreen, ImageGrid, TimerBar, Choices, ResultScreen
```
